How to read this run

One pass from evidence to execution

Three fixed moving-average hypotheses are measured on development and validation segments. Only validation chooses the holdout strategy. If every score is nonpositive, the system holds cash. Each period starts flat, and the order manager enforces risk approval and deduplicates simulated order IDs.

SIMULATION ONLY · Prices are fictional. Margin is illustrative; missing timestamps cannot verify session hours. Exchange holidays, market impact, and brokerage fills are not modeled. No Databento credits or real money are used.
