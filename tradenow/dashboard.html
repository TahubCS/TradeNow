    Slippage is in basis points; positive is a cost. Per-order detail: python -m tradenow paper-report

    Daily routine

    Run in a terminal after Tiingo publishes the close

    1. Import the latest close, with today's date as the end
      python -m tradenow tiingo-import --start 2004-11-18 --end YYYY-MM-DD
    2. Plan the next session (reconciles and cross-checks data; sends nothing)
      python -m tradenow paper-plan
    3. If the plan has an order, approve it before 9:30 ET using the command in Latest plan.
    4. In an emergency, cancel everything and optionally sell GLD
      python -m tradenow paper-halt --reason "..." --flatten

    Alpaca paper fills are simulated and can differ from live execution. Live trading is not supported.
